# Video Editor Skills

Skill per Claude Code che lo trasformano in un editor video "first-pass" per DaVinci Resolve Studio
(rough cut, pacing, B-roll, musica, sottotitoli, motion graphics Remotion/Figma, export YouTube).

- Fonte: https://github.com/appariciojunior/video-editor-skills (commit `6709678`)
- Autore: appariciojunior
- Licenza: CC BY-NC 4.0 (vedi `LICENSE-video-editor-skills`) — uso gratuito con attribuzione, **non commerciale**.

Skill incluse: video-editor-setup, edit-video, rough-cut, vlog-pacing, broll, resolve-scripting,
voice-and-audio, music-and-sound, captions, motion-overlays, figma-roundtrip, youtube-export.

Il template di configurazione citato da `video-editor-setup` si trova in
`video-editor-setup/templates/config.example.json`. `LEARNINGS-video-editor-skills.md` è la storia degli errori e delle correzioni dell'autore.
